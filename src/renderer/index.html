Keyboard shortcuts

Shortcuts work while this panel has focus, outside text fields, Settings, and Filters.

j / k
Next / previous visible notification
Enter
From search, focus the first result; on a link, open it
i
Mark the focused notification as read and move to the next row
Shift + E
Mark the focused notification as done
/
Focus search
?
Show this guide
Esc
Close this guide, Settings, or Filters

Navigation skips collapsed groups and stops at the ends. Read/Done affect only the focused row, never a group.

Turn off Keyboard shortcuts in Settings to disable character shortcuts and hide the toolbar help icon. Tab and Enter still work.
